\begin{itemize}
  \item \textbf{Hypothesis $H_1$ (continuous log-target regression):} regressing the charge target $Y = \log_{10}(\Dch/M)$ of Section~\ref{sec:preprocessing} directly minimizes the relative error: for $\Dch$ rebuilt with the true mass,
  \[
    \left| Y_{\mathrm{pred}} - Y_{\mathrm{true}} \right|^2 \approx \left( \frac{\Dch_{\mathrm{pred}} - \Dch_{\mathrm{true}}}{\Dch_{\mathrm{true}} \ln 10} \right)^2 \propto \mathrm{MARE}^2,
  \]
  so sub-percent MARE holds across the $\nsEdaDOrders$ orders of magnitude the neutron-star charge spans, without a classify-then-regress pipeline.
  \item \textbf{Hypothesis $H_2$ (turning-point gradient protection):} combining the Huber loss ($\delta = 1.0$)~\citep{Huber1964} with smooth GELU activations~\citep{Hendrycks2016_GELU} prevents gradient saturation at the turning point $dM/d\rhoc = 0$, reducing the $\Mmax$ boundary error by more than $50\%$ against standard MSE/ReLU networks.
  \item \textbf{Hypothesis $H_3$ (ResNet grid smoothing):} identity skip connections, $h^{(l+1)} = h^{(l)} + F(h^{(l)})$~\citep{He2016_ResNet}, let the network model the continuous variation in $\log_{10}\rhoc$ while interpolating smoothly across the discrete $(\beta, \lambda)$ grid steps, without residual step ripples.
\end{itemize}
