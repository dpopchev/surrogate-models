## Hypothesis
Can one scikit-learn pipeline around a skorch MLP, trained on the frozen curve-grouped split, beat the mean and nearest-curve reference predictors for each of the four dataset x target pairs, while it reports its progress live? Refuted if a pair's test MARE is not below its nearest-curve reference, or a validation curve also appears in training.

## Outcome
make baseline fits the four dataset x target pairs with live per-epoch progress and writes the Section 5.1 baseline table (test and fold MARE beside the mean and nearest-curve references), the NS mass parity figure, the charge MARE rebuilt with the true and the predicted mass, and one diagnostics folder per run under local/state/51_algorithms/.

## Acceptance criteria
- AC1 Given the prepared NS table and the frozen split, When the developer runs make baseline, Then build/assets/51_algorithms/ holds the NS mass test MARE macro and its parity figure -> W-034
- AC2 Given a finished baseline run, When it exits, Then local/state/51_algorithms/<run>/ holds its run record beside the loss, error and curve diagnostics -> W-035
- AC3 Given the four dataset x target pairs, When the developer runs make baseline, Then Section 5.1 shows each pair's test and fold MARE beside the mean and nearest-curve references -> W-036
- AC4 Given the NS and BH charge baselines, When make baseline runs, Then Section 5.1 reports the charge MARE rebuilt with the true M beside the one rebuilt with the predicted M -> W-037
