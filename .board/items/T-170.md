## Action
Skill build-with-tdd. shared/scorecard.py's ripple(residual, across, fixed) (T-129) needs rows aligned on a grid, but the test curves sample their along-curve input at their own points (rho_c for NS, r_h for BH, whose range moves with beta). In shared/harness.py, per run: interpolate each test curve's true target along its along-curve input (a cubic spline, which the W-064 along-curve ceiling shows is far below the model error) onto a shared grid over the overlap of the curves that differ only in one curve parameter; the residual is the candidate's prediction on that grid minus the interpolated truth; the run's ripple is ripple() of the residual across that curve parameter (beta; for NS also lambda) at fixed grid point and other parameters. Run gains a ripple field; the ledger entry (shared/runs.py) and the family screen's scorecard carry it. Tests on the harness's toy design: a candidate that predicts the truth has ripple 0; a candidate whose error alternates in sign across adjacent curves has a ripple above the same candidate with a constant error.

## Output
Every harness run carries its ripple, kept in its ledger entry.
