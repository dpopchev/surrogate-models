## Hypothesis
Does one data processing pipeline -- given a dataset, its data ceiling (the minimal relative error the dataset allows) and its physical domain -- build a surrogate that reaches the ceiling inside the domain and refuses an input outside it, with the same properties on the two-parameter black-hole map (beta, r_h) -> (M, D) and the three-parameter neutron-star map (rho_c, beta, lambda) -> (M, D)? Refuted for a pair when its surrogate stays more than one significant figure below its ceiling; a refuted pair is reported, never hidden.

## Outcome
article.pdf is a short physics-first paper -- the framework, the pipeline as an algorithm, the domain of validity, the results on both maps, their physical implications -- with the data science in the appendix; every section is a module that make rebuilds on its own into build/sections/<section>/, the interim results under local/state/, the root make layer configuration only.
