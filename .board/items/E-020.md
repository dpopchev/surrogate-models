## Hypothesis
Can make surrogates and make assets reuse every fit and every evaluation whose inputs are unchanged, so that a rerun with nothing changed ends in minutes instead of five hours and a change to one candidate refits that candidate alone?

## Outcome
make families, make tuning and make surrogates print each job as reused or fitted and fit only the jobs whose pair, candidate, parameters, seed or data changed; make assets predicts again only for a surrogate that was refitted.

## Acceptance criteria
- AC1 Given the recorded family screen and unchanged data, When the developer runs make families with FAMILIES_BATCH empty, Then every job is printed as reused from the recorded batch with nothing fitted -> W-198
- AC2 Given the recorded tuning batch and unchanged data, When the developer runs make tuning with TUNING_BATCH empty, Then every search is printed as reused from its recorded trials with nothing fitted -> W-199
- AC3 Given a rung that writes no batch, a record written and read back, and two batch files around a rung start, When the developer runs make test K=chain_edge, Then it passes with one test per case -> W-183
- AC4 Given a recorded make surrogates run, When the developer runs make surrogates REFIT=XGBoost, Then each rung fits the XGBoost jobs alone with every other job printed as reused -> W-200
- AC5 Given built assets and saved surrogates that did not change, When the developer runs make assets after an edit of one paperlib module, Then each section that scores a saved surrogate prints its held-out predictions as reused -> W-201
