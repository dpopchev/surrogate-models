## Hypothesis
Can every screen take its run shell helpers and its toy inputs from one shared module each, with no copy left in a section folder and every test still green?

## Outcome
Given the screens of 51_algorithms, 61_representation, 62_families and 63_precision, When the developer runs make check, Then it passes with every shell helper and the screens' toy inputs defined in one place each (shared/batches.py, 60_results/conftest.py) and none in a section module.

## Findings
- 2026-10-11 fact: a conftest.py per folder works here (section fixtures reach subfolders, a folder's own overrides, refusals intact) only with --ignore=conftest.py --ignore-glob=*/conftest.py: --doctest-modules imports each conftest as module conftest -> import file mismatch
