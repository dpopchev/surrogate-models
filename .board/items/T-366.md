Files: 40_data_analysis/41_neutron_stars/eda_neutron_stars.py, 40_data_analysis/42_black_holes/eda_black_holes.py, their .mk files and test modules. RED first: test_ns_eda_draws_every_variant_as_its_own_file runs the main step, then the figures mode, on the toy table of its test module and asserts the set of PNG names equals the 15 expected. The black-hole script gets the same mode, proven by a run: its --figures mode writes 14 files.
