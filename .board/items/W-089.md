  input: shared/scorecard.py ripple(residual, across, fixed) (T-129) on the test curves of the frozen split, whose curve parameters are an uneven subset of the grid -- the NS test betas at one lambda, the BH test betas 4.05, 4.55, 4.70
  actual: ripple takes plain second differences of the residuals ordered by `across`, ignoring their spacing, so a residual linear in the curve parameter scores a nonzero ripple whenever the spacing is uneven -- its docstring's "zero for a residual linear in across" holds only on an even grid; T-170 would measure the split's spacing, not the candidate's smoothness
  expected: a residual linear in `across` scores 0 at any spacing; the ripple measures the residual's curvature across the curve parameter
  steps: ripple(0.3 + 0.1 * a, a, zeros) with a = [1, 2, 4] returns 0.0 for an even grid but not for this one (second difference of [0.4, 0.5, 0.7] is 0.1)
  technical: replace the second difference by the second divided difference, 2 [ (r3 - r2)/(a3 - a2) - (r2 - r1)/(a2 - a1) ] / (a3 - a1), which is 0 for any linear residual and, on an even grid of step h, is the second difference over h^2 -- so the ripple's unit becomes residual per unit of the curve parameter squared; the existing T-129 tests (linear on an even grid scores 0, an alternating residual scores 2) change their expected value only where h differs from 1.

## Hypothesis
Does the second divided difference make the ripple of a linear residual zero at any spacing of the curve parameter?

## Outcome
Given a residual linear in the curve parameter on an unevenly spaced grid, When ripple() scores it, Then it returns 0.
