## Hypothesis
Can a file list of the previous upload tell, on each run, exactly which files to add and which to delete on Overleaf?

## Outcome
Given a previous upload list, When make overleaf runs with nothing changed, Then it reports 0 files added and 0 removed.

## Findings
- 2026-10-06 open: each make overleaf run refreshes local/overleaf/last-upload.txt, so two runs before one upload lose the first run's removed list -- refresh only on an explicit 'uploaded' step instead?
