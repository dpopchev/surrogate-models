## Hypothesis
Can every figure label be typeset from the macro file the preamble inputs, with no module spelling a symbol by hand?

## Outcome
Given the notation macros in 00_metadata/notation.tex, When make assets runs, Then every figure label is typeset through text.latex.preamble from that file and no figure module defines a dict of hand-spelled symbols.
