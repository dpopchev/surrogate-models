## Findings
- 2026-10-04 T-017: fact: 1850 blocks, each a '#' line (x1, x2, beta, Lambda, Pc, choice_theory) then a 27-column header then rows; one header layout; 224597 rows, all finite, D > 0 and M > 0 -> parse per block; outline N = 224597 is the unfiltered count

- 2026-10-04 T-017: fact: header beta and Lambda equal the beta and lambda columns; x1, x2, Pc, choice_theory, kappa (1000), mphi (0), lambda_phi (0), TheoryType (31) are constant -> assert them, inputs are (beta, lambda, rhoc)
