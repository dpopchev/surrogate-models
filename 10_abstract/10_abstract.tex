\begin{itemize}
  \item \textbf{Computational problem:} solving the extended scalar-tensor-Gauss--Bonnet (ESTGB) field equations inside Bayesian inference, which needs $10^5$--$10^7$ evaluations, is a severe computational bottleneck~\citep{Reed2024}.
  \item \textbf{Physical scope:} a dual-branch surrogate framework for vacuum curvature-induced scalarized black holes, the 2D map $(\rh, \beta) \to (M, \Dch)$~\citep{Doneva2017_BH}, and matter-coupled scalarized neutron stars, the 3D map $(\beta, \lambda, \rhoc) \to (M, \Dch)$~\citep{Doneva2017_NS}.
  \item \textbf{Contribution:} a processing pipeline that is the algorithm for building such surrogates (Section~\ref{sec:pipeline}): it minimizes the relative error against the data ceiling, extrapolates beyond the sampled curves, and flags an out-of-domain input with feedback on the nearest valid one (Section~\ref{sec:validity}).
  \item \textbf{Validation:} the same pipeline applied to the two-parameter black-hole map and to the three-parameter neutron-star map (Section~\ref{sec:results}); the data-science detail behind its design ($H_1$, $H_2$, $H_3$, the exploratory analysis) is the appendix.
  \item \textbf{Key results:} sub-percent mean absolute relative errors across the $\nsEdaDOrders$ orders of magnitude the dilaton charge $\Dch$ spans, and speedups of $10^2$--$10^4\times$ (to be measured, Section~\ref{sec:budget}).
\end{itemize}
